# Tools

开箱即用的小工具集合。

> 工具列表的权威来源是 `src/data/projects.js`。新增工具只需在该文件追加一条记录并创建对应视图文件（`src/views/<PascalName>.vue`），路由会自动生成（见 `src/router.js`），无需手动维护路由表。

## 工具

### API 融合应用（多 API 协作）
- **Trip Prep** — 旅行准备台：一屏搞定出行准备（国家、天气、汇率、时差、日出日落、空气质量、周边地震）
- **Earth Now** — 此刻地球：地震、ISS、极光、发射、火星天气、在轨人数
- **City Dashboard** — 城市仪表盘：天气、温度与空气质量双轴图、日出日落、周边地震
- **Repo Deep Dive** — 仓库深挖：GitHub 仓库统计、语言节点图、贡献者、提交活动

### 太空
- **ISS Tracker** — 空间站追踪
- **Mars Weather** — 火星天气
- **Aurora Forecast** — 极光预报
- **Launch Board** — 发射日程

### 数据
- **Trending Atlas** — 趋势仓库
- **Repo Scope** — 仓库透视
- **Node Atlas** — 节点情报
- **Atlas Info** — 国家百科
- **Hour Bridge** — 时区桥梁
- **Earthquake** — 地震监测
- **Dev Tools** — 开发者工具箱
- **Offday Planner** — 假期规划
- **QR Forge** — 二维码工坊
- **Password Vault** — 密码保险箱
- **Markdown Studio** — Markdown 工作室
- **Word Forge** — 单词工坊
- **HN Reader** — HN 阅读器

### 金融
- **Rate Board** — 汇率看板
- **Crypto Pulse** — 加密行情

### 地理
- **Sky Brief** — 天气简报
- **Sun & Moon** — 日出日落
- **Air Quality** — 空气质量

### 媒体
- **Radio Atlas** — 全球电台
- **Book Finder** — 找书助手
- **Movie Quest** — 影视搜索

### 美食 / 娱乐
- **Taste Atlas** — 美食图谱
- **Cocktail Bar** — 鸡尾酒吧
- **Meme Forge** — 梗图工坊

每个工具独立运行，互不依赖。
